## 🎮 О проекте

**КотоБайт** — это динамичная аркадная игра, в которой вы управляете котиком Барсиком, случайно попавшим в цифровой мир. Собирайте байты (монеты), получайте бусты, избегайте вирусов-призраков и обезвреживайте бомбы, чтобы набрать максимальное количество очков за 10 минут.

🔗 **Играть онлайн:** [kotobyte.netlify.app](https://kotobyte.netlify.app)

## ✨ Особенности

### 🎯 Геймплей
- **Система комбо** — собирайте монеты подряд для увеличения множителя очков (до x5)
- **Прогрессивная сложность** — каждые 2 минуты игра становится сложнее: появляются новые враги, они ускоряются
- **4 типа бустов** — ускорение, щит, удвоение очков, магнит
- **3 типа дебаффов** — замедление, темнота, инверсия управления
- **Бомбы с таймером** — обезвредьте бомбу, коснувшись призрака за 8 секунд

### 🏆 Достижения
Система из 8 уникальных достижений с сохранением прогресса:
- 🪙 **Первые байты** — соберите 10 монет
- 🔥 **Мастер комбо** — достигните x5 комбо
- ⏱️ **Выживший** — продержитесь 5 минут
- 💣 **Сапёр** — обезвредьте 3 бомбы
- 💰 **Богач** — наберите 1000 очков
- ⚡ **Демон скорости** — соберите 50 монет за игру
- 🛡️ **Неуязвимый** — пройдите 3 минуты без урона
- 👑 **Идеальная игра** — наберите 2000 очков

### 🎨 Визуальные эффекты
- Анимированный фон с движущейся сеткой
- Система частиц при сборе монет
- Двухслойный шлейф при рывке
- Эффект "фонарика" при дебаффе темноты
- Конфетти при победе
- Плавные переходы между сценами

### 🔊 Аудио
- Фоновая музыка с возможностью регулировки громкости
- Звуковые эффекты для всех действий
- Отдельные настройки для музыки и звуков
- Автоматическая разблокировка аудио при первом взаимодействии

### 💾 Сохранения
- Рекорды сохраняются в LocalStorage
- Прогресс достижений сохраняется между сессиями
- Туториал показывается только при первом запуске

## 🕹️ Управление

| Клавиша | Действие |
|---------|----------|
| ← → ↑ ↓ | Движение котика |
| Пробел | Рывок (dash) сквозь призраков |
| Esc | Пауза / Меню паузы |
| P | Пауза (альтернативная) |

## 🛠️ Технологии

- **JavaScript (ES6+)** — основной язык программирования
- **Phaser 3** — игровой фреймворк для 2D-игр
- **HTML5 Canvas** — рендеринг графики
- **Web Audio API** — управление звуком
- **LocalStorage API** — сохранение данных
- **Netlify** — хостинг и деплой
